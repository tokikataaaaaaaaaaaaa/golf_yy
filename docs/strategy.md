## 1. MVP Scope Definition

### 1.1 コア課題

- **Who（誰）:** 日本の20代ゴルファー（約74万人）
- **Problem（課題）:** ゴルフ仲間が少なく、一緒にラウンドできる相手が見つからない
- **Solution（解決策）:** 20代限定でラウンド相手をマッチング。企画者無料、参加者300円/マッチ成立

### 1.2 MoSCoW分類

#### Must Have（MVP必須）

| 機能ID | 機能名 | 理由 |
|--------|--------|------|
| M001 | 年齢認証（20代限定） | コアコンセプト。差別化ポイント |
| M002 | ユーザー登録・ログイン | 基本機能 |
| M003 | プロフィール作成 | マッチング判断に必須 |
| M004 | ラウンド募集投稿 | 企画者側のコア機能 |
| M005 | 募集検索・閲覧 | 申込者側のコア機能 |
| M006 | 参加申込 | 申込者が「参加したい」を送信 |
| M007 | 申込者承認/却下 | 企画者が申込を確認 |
| M008 | マッチ成立通知 | 双方OK時に連絡先交換を可能に |
| M009 | 決済機能（300円課金） | 収益の核心 |
| M010 | ユーザー間メッセージ | マッチ成立後の詳細調整 |
| M011 | 通報・ブロック機能 | 安全性担保 |

### 1.3 ユーザーフロー

```
【企画者フロー】
1. ログイン → プロフィール作成
2. ラウンド募集投稿（日時、場所、レベル、定員）
3. 申込通知を受け取る
4. 申込者プロフィール確認 → OK/NG選択
5. マッチ成立 → メッセージで詳細調整

【申込者フロー】
1. ログイン → プロフィール作成
2. 募集を検索・閲覧
3. 気に入った募集に「参加したい」申込
4. 企画者の承認待ち
5. マッチ成立 → 300円課金 → メッセージで詳細調整
```

## 2. Tech Stack Selection

### 2.1 Full Stack Overview

```
Frontend:  Next.js 14 + PWA + Tailwind CSS + Zustand
Backend:   Supabase (Edge Functions for custom logic)
Database:  PostgreSQL (Supabase)
Auth:      Supabase Auth (Google/Apple/LINE)
Payment:   Stripe (Checkout + Webhooks)
Realtime:  Supabase Realtime
Hosting:   Vercel (Frontend) + Supabase (Backend)
Storage:   Supabase Storage
```

### 2.2 選定理由

| 技術 | 選定理由 |
|------|---------|
| **Next.js + PWA** | App Store審査回避（マッチングアプリは厳格）、Web/iOS/Android同時カバー |
| **Supabase** | BaaSでインフラ管理不要、PostgreSQLで複雑なクエリ対応、Realtime内蔵 |
| **Stripe** | グローバルスタンダード、年齢確認（Stripe Identity）も統合可能 |
| **Vercel** | Next.jsとの完全統合、ゼロダウンタイムデプロイ |

### 2.3 コスト試算

| 項目 | 月額 |
|------|------|
| Vercel Pro | $20 (約3,000円) |
| Supabase Pro | $25 (約3,750円) |
| ドメイン | 約125円 |
| **合計** | **約7,000-8,000円/月** |

**制約条件「月1-2万円」を余裕でクリア**

### 2.4 開発工数見積もり

| 機能 | 工数 |
|------|------|
| 認証・プロフィール | 1週間 |
| ラウンド募集 CRUD | 1週間 |
| 検索・フィルタ | 1週間 |
| マッチング機能 | 1週間 |
| 決済連携 | 1週間 |
| リアルタイムメッセージ | 1週間 |
| 通報・ブロック | 3日 |
| PWA対応・UI調整 | 1週間 |
| テスト・バグ修正 | 1週間 |
| **合計** | **約8週間** |

### 2.5 技術的リスクと対策

| リスク | 対策 |
|--------|------|
| PWAのプッシュ通知が届かない | LINE公式アカウント連携で通知代替 |
| Stripe手数料が高い（300円課金時17%） | クレジット購入制/月額プランを検討 |
| 身分証OCRの精度 | MVP時は手動確認、後でStripe Identity導入 |

## 3. Marketing Strategy

### 3.1 Positioning

**ポジショニングステートメント:**

> 首都圏の20代ゴルファーに向けた、
> 同世代限定のゴルフ仲間マッチングサービス。
> スイングサプリより安く（300円 vs 500円）、企画者は無料。
> 気兼ねなく一緒にラウンドできる仲間を、低コストで見つけられる。

**競合との差別化:**

| 競合 | golf_yyの差別化ポイント |
|------|------------------------|
| スイングサプリ | **企画者無料**（スイングサプリは全員課金）、参加者300円（500円より40%安い） |
| 楽天GORA/GDO 1人予約 | 20代限定で同世代のみ |
| ゴルマチ/GolWho | マッチング後に課金モデルで本気度フィルタリング |

### 3.2 Messaging

**キャッチコピー（メイン）:**
> 「20代だけ。気兼ねない、ゴルフ仲間。」

**サブコピー（SNS広告用）:**
> 「おじさんゼロ保証。」

**Tone & Voice:**
- カジュアル・フレンドリー
- 20代が友達に話すような口調

### 3.3 Channel Strategy

**Primary Channels（月5万円）:**

| チャネル | 予算 | 目標 |
|----------|------|------|
| X（Twitter）広告 | 3万円 | 40人登録 |
| Instagram広告 | 2万円 | 30人登録 |
| X運用（オーガニック） | 0円 | 30人登録 |

### 3.4 Launch Approach

**東京ローンチ（スイングサプリと直接競合）:**

| Phase | 期間 | 対象エリア | 目標 |
|-------|------|-----------|------|
| Phase 1 | 0-6週間 | 東京都 | 登録100人、マッチ10件 |
| Phase 2 | 6-12週間 | 東京・神奈川・千葉・埼玉 | 登録300人 |
| Phase 3 | 3ヶ月後 | 全国 | 登録500人、マッチ30件/月 |

**スイングサプリとの競合戦略:**
- 価格優位性を前面に（企画者無料、参加者300円 vs 500円）
- 「スイングサプリより安い」を明確に訴求
- スイングサプリの不満点をヒアリングして改善

**初期100人獲得の具体策:**

| 施策 | 目標 | コスト |
|------|------|--------|
| X運用 | 30人 | 0円 |
| X広告（東京ターゲティング） | 40人 | 3万円 |
| Instagram広告 | 30人 | 2万円 |

## 5. Risks & Mitigation

| リスク | 影響度 | 対策 |
|--------|--------|------|
| スイングサプリとの直接競合 | 高 | 価格優位性（300円 vs 500円）と企画者無料で差別化 |
| ユーザー獲得困難 | 高 | 東京に集中投下、スイングサプリユーザーへのアプローチ |
| 課金意欲の低さ | 高 | ローンチ前に20人インタビュー実施 |
| App Store審査 | 中 | PWAで審査回避 |
| マッチング成立率の低さ | 中 | 初期は企画者インセンティブ |
| スイングサプリの価格対抗 | 中 | 企画者無料という独自モデルで差別化維持 |
