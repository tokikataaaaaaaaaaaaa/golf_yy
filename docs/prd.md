## 2. 機能要件（Must Have）

### F-001: 年齢認証（20代限定）

**ユーザーストーリー:**
20代ゴルファーとして、同世代だけのコミュニティに参加したい。なぜなら、年齢層が近い仲間と気兼ねなくゴルフを楽しみたいから。

**受け入れ基準:**
- [ ] Given: ユーザーが生年月日を入力する
  - When: 年齢が20〜29歳の場合
  - Then: 登録処理を続行できる
- [ ] Given: ユーザーが生年月日を入力する
  - When: 年齢が19歳以下または30歳以上の場合
  - Then: 「20代限定サービスです」エラーを表示し、登録を拒否する
- [ ] Given: ユーザーが未来の日付を入力する
  - When: 生年月日が現在日以降の場合
  - Then: 「有効な生年月日を入力してください」エラーを表示する

**UI/UX要件:**
- 生年月日入力フォーム（年/月/日のドロップダウン）
- 入力時にリアルタイムで年齢計算・表示
- エラー時は明確なメッセージを表示

**エラーハンドリング:**
- 不正な日付形式 → 「有効な日付を入力してください」
- 年齢範囲外 → 「golf_yyは20代限定サービスです」

### F-002: ユーザー登録・ログイン

**ユーザーストーリー:**
新規ユーザーとして、簡単に登録・ログインしたい。なぜなら、面倒な入力作業を省いてすぐにサービスを使い始めたいから。

**受け入れ基準:**
- [ ] Given: 未登録ユーザーがアプリにアクセスする
  - When: Google/Apple/LINEアカウントで登録を選択する
  - Then: OAuth認証後、年齢確認画面に遷移する
- [ ] Given: 登録済みユーザーがアプリにアクセスする
  - When: 前回と同じ認証方法でログインする
  - Then: ホーム画面に直接遷移する
- [ ] Given: ログイン済みユーザー
  - When: 7日間アクティビティがない場合
  - Then: 再ログインを要求する
- [ ] Given: ユーザーがログアウトを選択する
  - When: ログアウトボタンを押す
  - Then: セッションを破棄し、ログイン画面に遷移する

**UI/UX要件:**
- SNS認証ボタン（Google/Apple/LINE）を大きく表示
- メールアドレス登録は非対応（MVP）
- ログイン状態を7日間維持

**エラーハンドリング:**
- OAuth認証失敗 → 「認証に失敗しました。再度お試しください」
- ネットワークエラー → 「通信エラーが発生しました」

### F-003: プロフィール作成

**ユーザーストーリー:**
新規登録ユーザーとして、自分のプロフィールを作成したい。なぜなら、ラウンド相手に自分のことを知ってもらい、マッチング精度を高めたいから。

**受け入れ基準:**
- [ ] Given: 年齢認証を通過したユーザー
  - When: プロフィール作成画面に遷移する
  - Then: 必須項目入力フォームが表示される
- [ ] Given: ユーザーが必須項目をすべて入力する
  - When: 保存ボタンを押す
  - Then: プロフィールが保存され、ホーム画面に遷移する
- [ ] Given: ユーザーが必須項目を未入力で保存しようとする
  - When: 保存ボタンを押す
  - Then: 未入力項目がハイライトされ、エラーメッセージを表示する

**必須項目:**
| 項目 | 形式 | バリデーション |
|------|------|--------------|
| ニックネーム | テキスト | 2〜20文字 |
| 性別 | 選択式 | 男性/女性/その他 |
| 居住エリア | 選択式 | 都道府県 |
| ゴルフ歴 | 選択式 | 1年未満/1-3年/3-5年/5年以上 |
| 平均スコア | 選択式 | 〜90/91-100/101-110/111-120/121-130/131〜 |
| 自己紹介 | テキスト | 10〜200文字 |

**任意項目:**
| 項目 | 形式 | バリデーション |
|------|------|--------------|
| プロフィール写真 | 画像 | JPG/PNG、5MB以下 |
| ホームコース | テキスト | 50文字以下 |

**UI/UX要件:**
- ステップ形式（3画面に分割）で入力負荷を軽減
- プログレスバーで進捗表示
- 写真はカメラ撮影またはギャラリーから選択

**エラーハンドリング:**
- 画像サイズオーバー → 「5MB以下の画像を選択してください」
- 文字数超過 → リアルタイムで残り文字数を表示

### F-004: ラウンド募集投稿

**ユーザーストーリー:**
企画者として、ラウンド募集を投稿したい。なぜなら、自分の都合に合った日時・場所で一緒にラウンドする仲間を見つけたいから。

**受け入れ基準:**
- [ ] Given: ログイン済みユーザー
  - When: 「募集を作成」ボタンを押す
  - Then: 募集作成フォームが表示される
- [ ] Given: ユーザーが必須項目をすべて入力する
  - When: 投稿ボタンを押す
  - Then: 募集が公開され、一覧に表示される
- [ ] Given: ラウンド日が過去の日付
  - When: 投稿しようとする
  - Then: 「未来の日付を選択してください」エラーを表示
- [ ] Given: 企画者が自分の募集を編集する
  - When: 編集ボタンを押す
  - Then: 募集内容を変更できる（申込者がいない場合のみ）
- [ ] Given: 企画者が自分の募集を削除する
  - When: 削除ボタンを押す
  - Then: 確認ダイアログ後、募集が削除される

**必須項目:**
| 項目 | 形式 | バリデーション |
|------|------|--------------|
| ラウンド日 | 日付 | 今日以降〜3ヶ月以内 |
| 集合時間 | 時刻 | 5:00〜18:00 |
| ゴルフ場名 | テキスト | 2〜50文字 |
| エリア | 選択式 | 都道府県 |
| 募集人数 | 選択式 | 1〜3人 |
| 希望レベル | 選択式 | 初心者歓迎/中級者/上級者 |

**任意項目:**
| 項目 | 形式 | バリデーション |
|------|------|--------------|
| コメント | テキスト | 200文字以下 |
| 予算目安 | 選択式 | 〜1万円/1〜1.5万円/1.5〜2万円/2万円〜 |

**UI/UX要件:**
- 日付選択はカレンダーUI
- ゴルフ場名はフリーテキスト（MVPでは検索機能なし）
- 投稿後は「募集中」ステータスで表示

**エラーハンドリング:**
- 同時刻に既存募集あり → 「同じ日時に別の募集があります」警告

### F-005: 募集検索・閲覧

**ユーザーストーリー:**
申込者として、自分に合ったラウンド募集を探したい。なぜなら、日程・場所・レベルが合う相手と効率よくマッチングしたいから。

**受け入れ基準:**
- [ ] Given: ログイン済みユーザー
  - When: ホーム画面を開く
  - Then: 募集一覧が表示される（新しい順）
- [ ] Given: ユーザーがフィルターを設定する
  - When: 日付/エリア/レベルを選択する
  - Then: 条件に合った募集のみ表示される
- [ ] Given: 募集一覧が表示されている
  - When: 募集カードをタップする
  - Then: 募集詳細画面に遷移する
- [ ] Given: 検索条件に合う募集がない
  - When: 検索結果が0件
  - Then: 「条件に合う募集がありません」メッセージを表示

**フィルター項目:**
| 項目 | 形式 |
|------|------|
| 日付 | 今週末/来週/今月/来月/日付指定 |
| エリア | 都道府県（複数選択可） |
| レベル | 初心者歓迎/中級者/上級者（複数選択可） |

**UI/UX要件:**
- 募集カードには日付、ゴルフ場、企画者名、レベルを表示
- 無限スクロールで追加読み込み
- フィルターはモーダルで表示

**エラーハンドリング:**
- 読み込み失敗 → 「読み込みに失敗しました。再試行してください」

### F-006: 参加申込

**ユーザーストーリー:**
申込者として、気になる募集に参加申込したい。なぜなら、企画者に自分の参加意思を伝えたいから。

**受け入れ基準:**
- [ ] Given: ユーザーが募集詳細画面を開いている
  - When: 「参加したい」ボタンを押す
  - Then: 申込が送信され、ステータスが「申込中」に変わる
- [ ] Given: ユーザーが既に申込済みの募集
  - When: 募集詳細画面を開く
  - Then: 「申込済み」と表示され、申込ボタンが非活性
- [ ] Given: ユーザーが自分の募集
  - When: 募集詳細画面を開く
  - Then: 「参加したい」ボタンが表示されない
- [ ] Given: 募集が定員に達している
  - When: 募集詳細画面を開く
  - Then: 「定員に達しました」と表示される

**UI/UX要件:**
- 申込前に確認ダイアログを表示
- 申込後は「申込一覧」から状態確認可能
- プッシュ通知で申込結果を通知

**エラーハンドリング:**
- 申込送信失敗 → 「申込に失敗しました。再試行してください」

### F-007: 申込者承認/却下

**ユーザーストーリー:**
企画者として、申込者を確認して承認/却下したい。なぜなら、一緒にラウンドする相手を自分で選びたいから。

**受け入れ基準:**
- [ ] Given: 企画者に新しい申込が届く
  - When: 通知をタップする
  - Then: 申込者のプロフィールが表示される
- [ ] Given: 企画者が申込者プロフィールを確認する
  - When: 「承認」ボタンを押す
  - Then: マッチ成立処理が開始される
- [ ] Given: 企画者が申込者プロフィールを確認する
  - When: 「却下」ボタンを押す
  - Then: 申込が却下され、申込者に通知される
- [ ] Given: 募集の定員に達した
  - When: 最後の申込者を承認する
  - Then: 募集ステータスが「締切」に変わる

**UI/UX要件:**
- 申込者一覧はプロフィール写真・名前・ゴルフ歴・スコアを表示
- スワイプで承認/却下（または個別ボタン）
- 承認/却下後は取り消し不可（確認ダイアログで確認）

**エラーハンドリング:**
- 承認処理失敗 → 「処理に失敗しました。再試行してください」

### F-008: マッチ成立通知

**ユーザーストーリー:**
ユーザーとして、マッチが成立したことを即座に知りたい。なぜなら、ラウンドの詳細を早く調整したいから。

**受け入れ基準:**
- [ ] Given: 企画者が申込を承認する
  - When: マッチが成立する
  - Then: 企画者と申込者の両方にプッシュ通知が送信される
- [ ] Given: マッチ成立通知を受け取る
  - When: 通知をタップする
  - Then: メッセージ画面に遷移する
- [ ] Given: マッチが成立する
  - When: 申込者のマッチ一覧を開く
  - Then: 新しいマッチが一覧に表示される

**通知内容:**
- 企画者向け: 「〇〇さんとのマッチが成立しました」
- 申込者向け: 「〇〇さんの募集とマッチしました」

**UI/UX要件:**
- プッシュ通知 + アプリ内通知
- 通知センターに履歴を表示
- 未読バッジで新着を表示

**エラーハンドリング:**
- プッシュ通知送信失敗 → アプリ内通知のみ表示

### F-009: 決済機能（300円課金）

**ユーザーストーリー:**
申込者として、マッチ成立時に300円を支払いたい。なぜなら、サービス利用の対価として適正な費用を負担したいから。

**受け入れ基準:**
- [ ] Given: マッチが成立する
  - When: 申込者に決済画面が表示される
  - Then: 300円の決済処理を実行できる
- [ ] Given: 申込者が決済を完了する
  - When: 決済が成功する
  - Then: メッセージ機能が解放される
- [ ] Given: 申込者が決済を完了する
  - When: 決済が失敗する
  - Then: 「決済に失敗しました」エラーを表示し、再試行を促す
- [ ] Given: 決済完了後
  - When: 決済履歴を確認する
  - Then: 日時・金額・相手の名前が表示される

**決済仕様:**
| 項目 | 内容 |
|------|------|
| 決済金額 | 300円（税込） |
| 決済方法 | クレジットカード（Stripe） |
| 課金タイミング | マッチ成立時 |
| 課金対象 | 申込者のみ（企画者は無料） |

**UI/UX要件:**
- Stripe Checkoutを使用（セキュリティ確保）
- カード情報はStripe側で保持（自社DBに保存しない）
- 決済完了画面で領収書表示

**エラーハンドリング:**
- カード認証失敗 → 「カード情報を確認してください」
- 残高不足 → 「残高不足です。別のカードをお試しください」
- ネットワークエラー → 「通信エラーが発生しました。再試行してください」

### F-010: ユーザー間メッセージ

**ユーザーストーリー:**
マッチした相手として、メッセージでラウンドの詳細を調整したい。なぜなら、集合時間・場所・当日の連絡先などを決めたいから。

**受け入れ基準:**
- [ ] Given: マッチが成立し、決済が完了している
  - When: メッセージ画面を開く
  - Then: 相手とのチャットが開始できる
- [ ] Given: ユーザーがメッセージを送信する
  - When: 送信ボタンを押す
  - Then: メッセージがリアルタイムで相手に届く
- [ ] Given: 相手からメッセージを受信する
  - When: アプリがバックグラウンドの場合
  - Then: プッシュ通知で通知される
- [ ] Given: マッチ成立前
  - When: メッセージ機能にアクセスしようとする
  - Then: 「マッチ成立後にメッセージが可能です」と表示

**UI/UX要件:**
- チャット形式のUI（LINE風）
- 既読表示あり
- 画像送信は非対応（MVP）
- メッセージ履歴は無期限保持

**エラーハンドリング:**
- 送信失敗 → 「送信に失敗しました」+ 再送信ボタン
- 接続エラー → 「接続中...」表示

### F-011: 通報・ブロック機能

**ユーザーストーリー:**
ユーザーとして、不適切なユーザーを通報・ブロックしたい。なぜなら、安全にサービスを利用したいから。

**受け入れ基準:**
- [ ] Given: ユーザーが相手のプロフィールを開く
  - When: 「通報」ボタンを押す
  - Then: 通報理由選択画面が表示される
- [ ] Given: ユーザーが通報理由を選択する
  - When: 送信ボタンを押す
  - Then: 通報が運営に送信される
- [ ] Given: ユーザーが相手のプロフィールを開く
  - When: 「ブロック」ボタンを押す
  - Then: 確認後、相手との接点がすべて非表示になる
- [ ] Given: ブロック済みのユーザー
  - When: 相手の募集を検索する
  - Then: 検索結果に表示されない

**通報理由:**
- 不適切な言動
- なりすまし・詐欺
- 迷惑行為
- 年齢詐称
- その他

**UI/UX要件:**
- 通報はプロフィール画面の「...」メニューから
- ブロックは即時反映
- ブロック解除は設定画面から可能

**エラーハンドリング:**
- 通報送信失敗 → 「通報の送信に失敗しました」

## 3. 非機能要件

### 3.1 パフォーマンス要件

| 項目 | 要件 |
|------|------|
| ページロード時間 | 3秒以内 |
| API応答時間 | 500ms以内（95パーセンタイル） |
| 同時接続ユーザー数 | 1,000人 |
| データベースクエリ | 100ms以内 |

### 3.2 セキュリティ要件

| 項目 | 要件 |
|------|------|
| 通信 | HTTPS必須（TLS 1.2以上） |
| 認証 | OAuth 2.0 + JWT |
| 個人情報 | AES-256で暗号化 |
| 決済 | PCI DSS準拠（Stripe委託） |
| CSRF対策 | トークン検証必須 |
| XSS対策 | 入力サニタイズ必須 |

### 3.3 運用要件

| 項目 | 要件 |
|------|------|
| 可用性 | 99%以上（月間7時間以内のダウンタイム） |
| バックアップ | 日次自動バックアップ |
| ログ | 全APIリクエストをログ出力 |
| 監視 | エラー率5%超でアラート |
| デプロイ | ゼロダウンタイムデプロイ |

## 4. 除外事項（Won't-have）

以下の機能はMVPに含まない：

| 機能 | 除外理由 |
|------|---------|
| SNS投稿機能 | v1.1以降で実装 |
| スコア管理 | v1.2以降で実装 |
| コンペ機能 | バックログ |
| 動画レッスン配信 | コアバリューと無関係 |
| ゴルフ用品EC | 別ビジネス |
| AIコーチング | 技術的難易度高 |
| 30代以上への拡大 | 差別化ポイントを維持 |
| ネイティブアプリ | PWAで開始、需要に応じて検討 |

## 5. 用語集

| 用語 | 定義 |
|------|------|
| **ラウンド** | ゴルフコースを18ホール（または9ホール）プレーすること |
| **企画者** | ラウンド募集を投稿するユーザー |
| **申込者** | ラウンド募集に参加申込するユーザー |
| **マッチング** | 企画者と申込者が双方承認し、一緒にラウンドすることが確定すること |
| **マッチ成立** | 企画者が申込を承認し、申込者が決済を完了した状態 |
| **レベル** | ゴルフの技量を示す区分（初心者/中級者/上級者） |
| **平均スコア** | 18ホールの平均打数 |
| **ゴルフ歴** | ゴルフを始めてからの期間 |
| **1人予約** | ゴルフ場が提供する、他の組に混ざってラウンドするサービス |
