## 2. Market Research Summary

### 2.1 市場規模・成長率

| 指標 | 数値 | 情報源 |
|------|------|--------|
| 日本ゴルフ市場 | 約1兆4,420億円（2023年） | 矢野経済研究所 |
| ゴルフ人口 | 912万人（2024年） | 笹川スポーツ財団 |
| 20代ゴルフ人口 | 74万2,000人 | 笹川スポーツ財団 |
| 20代参加率増加 | +4.0ポイント（2022→2024年） | 笹川スポーツ財団 |
| 新規参入の20-30代比率 | 58.5% | 矢野経済研究所 |

**評価:** ○ 成長市場

**根拠:**
- 20代の参加率が直近2年で4.0ポイント増加（全年代で最大の伸び）
- 新規参入ゴルファーの58.5%が20-30代
- 女性20代の実施率6.0%は過去最高

### 2.2 競合分析

| サービス | 20代特化 | SNS | スコア管理 | コンペ | 料金 |
|----------|---------|-----|-----------|-------|------|
| 楽天GORA | × | △ | ○ | ○ | 無料 |
| GDO | × | △ | ○ | ○ | 無料 |
| ゴルマチ | × | ○ | × | × | 無料 |
| GolWho | × | ○ | × | △ | 無料 |
| **スイングサプリ** | **◎** | △ | × | △ | 500円/回 |
| Pairs（ゴルフ） | × | ○ | × | × | 有料 |

**直接競合:** スイングサプリ（20-30代特化、首都圏9,000人、95%満足度）

### 2.3 ターゲット市場の妥当性

**20代ゴルファーの特徴:**
- 57.1%が「友人とのコミュニケーション」を目的としてゴルフ
- 41.3%が「友人に誘われて」ゴルフを始めた
- 仲間探しの既存手段（サークル、1人予約）に不満あり

**市場の空白:**
- 20代特化 × SNS × スコア管理 × コンペ機能の統合サービスが不在
- スイングサプリは首都圏限定、スコア管理機能なし

## 3. Feasibility Assessment

### 3.1 技術的実現可能性

| 機能 | 難易度 | 工数 |
|------|--------|------|
| ユーザー認証 | 低 | 1週間 |
| SNS機能 | 中 | 2-3週間 |
| マッチング | 中 | 2週間 |
| コンペ募集 | 中 | 2週間 |
| スコア管理 | 低〜中 | 1-2週間 |
| 決済機能 | 中〜高 | 2週間 |

**MVP開発期間:** 2-3ヶ月（フルタイム）

**評価:** ○ 一人開発で実現可能

### 3.2 一人開発での実現性

**強み:**
- 技術的に標準的な機能で構成
- ノーコード/ローコードで開発期間短縮可能
- 既存のBaaS（Firebase等）で運用負荷軽減

**課題:**
- マッチングアプリはApp Store審査が厳しい
- コミュニティ形成には時間がかかる
- スコア管理は既存アプリとの差別化が困難

## 5. Final Recommendation

### 判定: Conditional Go（条件付きGo）

**総合スコア: 5.2/10**

| 評価項目 | スコア |
|----------|--------|
| 市場魅力度 | 7/10 |
| 収益性 | 4/10 |
| 実現性 | 7/10 |
| 競争優位性 | 3/10 |
| リスク | 5/10 |

### Go判断の必須条件

1. **スイングサプリとの明確な差別化**
   - 地方特化（首都圏以外から開始）
   - スコア管理のゲーミフィケーション
   - 完全無料 + 別のマネタイズ

2. **収益モデルの事前検証**
   - 20代ゴルファー10人へのインタビュー
   - 課金意欲の確認
   - スイングサプリ離脱者へのヒアリング

3. **MVPスコープの絞り込み**
   - 最初は「マッチング機能」のみでテスト
   - SNS/スコア管理は後から追加

### MVP仕様（確定）

| 項目 | 内容 |
|------|------|
| **コア機能** | 20代限定ゴルフ仲間マッチング |
| **企画者**（ラウンド募集） | **無料** |
| **申込者**（参加希望） | **300円/マッチ** |
| **マッチ成立** | お互いがOKした時点で課金 |

**ユーザーフロー:**
1. 企画者: ラウンド募集を投稿（無料）
2. 申込者: 募集を見て「参加したい」
3. 企画者: 申込者を確認し「OK」or「NG」
4. 双方OK → マッチ成立 → 申込者に300円課金

### リスクと懸念事項

| リスク | 影響度 | 対策 |
|--------|--------|------|
| スイングサプリとの直接競合 | 高 | 地域/機能/価格で差別化 |
| 無料サービス優位の市場 | 高 | 課金価値の徹底訴求 |
| ユーザー獲得困難 | 中 | 地域限定で密度確保 |
| 大手の参入 | 中 | ニッチ戦略で対抗 |

### 次のステップ

| アクション | 期間 | 成功基準 |
|------------|------|---------|
| スイングサプリの実体験 | 1週間 | ユーザー体験を分析 |
| 20代ゴルファー10人インタビュー | 2週間 | 課金意欲50%以上 |
| 差別化ポイントの明確化 | 2週間 | 不満点3つ以上発見 |
| LPでウェイトリスト収集 | 4週間 | 登録100人以上 |

**検証完了後、最終的なGo/No-Go判断を行う**

## 6. 代替案（No-Goの場合）

1. **ゴルフ×異業種交流** - ビジネスパーソン向け、高単価
2. **スコア管理特化ツール** - AI分析、動画連携で差別化
3. **練習場向けB2Bサービス** - 集客支援ツール
